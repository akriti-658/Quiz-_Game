# Quiz-_Game
I made a project on python quiz game by using python essentials .This contains 5 multiple choice questions each have 4 choices and any one is correct  if you selected
correct answeryou get +1 and if you selected wrong answer than you get -1 than at the end of the quiz you get your total score and on the basis of that you get remarks .

#Project overview 
Python Quiz Game is a simple command-line application developed in Python .The program presents multiple- choice questions to the player , accepts answers through the
terminal ,checks the selected answers ,calculated the score , and displays the final result after the quiz is completed.

#Objectives
*Develop a basic interactive application using python
*Practice variables, lists/dictionaries ,loops, conditions, and user input
*Implement automatic answer validation and score calculation
*Provide a clear and easy-to-use command-line interface
*Create a project that can be easily extended with additional questions or features

#Main features 
*Multiple- choice quiz questions
*Interactive user input through the command line
*Automatic checking of answers
*Score calculation and final score display
*Simple question configuration
*No external packages required for the standard-library version 

#Troubleshooting
Python command is not recognised: Confirm that python is installed and added to PATH, then restart the terminal.
File not found: Check that the terminal is open in the project root directory and that the main Python filename is correct.
Invalid answer: Enter the answer in the format expected by the application , such as A,B,C or D.
